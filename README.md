# Plac Centralny — strona na GitHub Pages

Gotowa, responsywna strona HTML/CSS/JS. Wszystkie zdjęcia są lokalne; brak bibliotek, instalacji i płatnych usług. Otwórz index.html, aby obejrzeć stronę na komputerze.

## Wgranie
1. Rozpakuj ZIP.
2. Otwórz lub utwórz repozytorium GitHub, np. plac-centralny.
3. Wgraj zawartość folderu plac-centralny: index.html, style.css, script.js oraz cały folder assets. Plik index.html musi być w głównym katalogu repozytorium.
4. W ustawieniach repozytorium wybierz Pages, publikację z gałęzi (Deploy from a branch), gałąź main i katalog / (root). Zapisz.
5. Po publikacji adres będzie miał postać https://TWOJ-LOGIN.github.io/plac-centralny/ — GitHub pokaże rzeczywisty link w ustawieniach Pages.

## Edycja
Teksty i odnośnik do Google Maps: index.html. Wygląd: style.css. Powiększanie zdjęć: script.js. Zdjęcia: assets/*.webp.

## Materiały
Opis opracowano z przekazanego tekstu UM Warszawa. To niezależna strona informacyjna, nie oficjalna strona miasta. Trzy zdjęcia dostarczył zamawiający. Podany w materiale podpis „Cezary Warś | UM Warszawa” dotyczył podlinkowanej fotografii miejskiej, której nie pobierano; nie przypisano go automatycznie do innych zdjęć. Przed publicznym udostępnieniem należy potwierdzić prawa publikacji zdjęć oraz uzupełnić wymagane przez ich autorów podpisy.

## Dostępność
Polski język dokumentu, opisy zdjęć, widoczny fokus, nawigacja klawiaturą, zamykanie galerii klawiszem Escape, obsługa preferencji ograniczonego ruchu, układ mobilny. Nie przeprowadzono pełnego audytu WCAG.
